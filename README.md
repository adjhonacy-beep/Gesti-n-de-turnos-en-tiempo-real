la aplicación completa de gestión de turnos en tiempo real con las siguientes características:
Sincronización Multiusuario en Vivo: 
Todos los usuarios conectados ven instantáneamente el cambio de turno, el subtítulo actualizado y los mensajes del chat.
Perfiles y Restricciones:
Usuario 0 (Pantalla Pública):
Acceso directo sin contraseña; muestra únicamente el titular "TURNO", el subtítulo y el número gigante en pantalla completa, ocultando por completo el chat, los botones de avance/retroceso y el reinicio.
Operadores y Administrador: Cuentan con botones Anterior (-1) y Siguiente (+1), además del Chat en tiempo real para comunicarse entre puestos. (La clave inicial del Administrador por defecto es 1234).
Configuración y Modo Oscuro: Desde el botón superior derecho se puede activar la pantalla oscura con letras blancas, reiniciar el contador a 0 y, si eres Administrador, editar el subtítulo global y crear o eliminar usuarios.
